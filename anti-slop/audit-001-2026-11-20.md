## Findings

### Hard Gate (prioritas HIGH)

1. **R-02 — Em dash di teks UI.** Ada em dash (`—`) real di copy antarmuka, melanggar Hard Gate.
   - Bukti: `frontend/src/pages/admin/VerifikasiDetailPage.vue:238` ("Hasil berbeda dari laporan — catatan admin wajib").
   - `frontend/src/pages/admin/DetailPeminjamanPage.vue:226, 302` ("... — ...", "{{ nama }} — dilaporkan ...").
   - `frontend/src/pages/admin/BarangPage.vue:272`, `frontend/src/pages/admin/StokRusakPage.vue:166` ("{{ aksi }} — {{ nama }}").
   - Fallback `?? '—'` dipakai beberapa tabel/detail (TabelData, VerifikasiPage, DasborPage, PeminjamanPage, BarangPage, AuditPage, VerifikasiDetailPage, DetailPeminjamanPage) sebagai placeholder/sep — catat, bukan fail besar.

2. **R-35 — Deliverable belum terverifikasi.** Frontend belum di-build/dijalankan di sesi audit ini, dan belum ada click-through terdokumentasi. Cek Delivery Gate belum bisa lakukan PASS penuh.

### Purpose-Gate (prioritas MEDIUM)

3. **R-06 — Tipografi tanpa alasan.** Semua font pakai `font-sans` system-ui default (`main.css:4`). Tidak ada alasan karakter merek tertulis.

4. **R-09 — Badge/pill berlebihan atau tanpa fungsi.** Kartu menu kiosk pakai pill `bg-white/20 uppercase` + badge warna solid (blue/emerald/indigo) di `BerandaPage.vue:102`, pola template.

5. **R-19 — Animasi berbasis kelas tak terpasang.** `ModalKonfirmasi.vue:90` pakai `animate-in fade-in zoom-in-95 duration-150`; plugin `tailwindcss-animate` tidak ada di `frontend/package.json`. Animasi sebenarnya tidak jalan.

### Quality Locks (prioritas LOW)

6. **R-39 — cursor hilang.** Tombol toggle sidebar di `Navbar.vue:22` tidak ada `cursor-pointer`.

7. **R-05 — Pola layout template.** Hero + kartu menu 3 kolom seragam + info box di `BerandaPage.vue:39-129`; kartu menu pakai warna solid Tailwind identik (blue/emerald/indigo).

8. **R-08 — Panah dekoratif.** `&rarr;` di kartu menu (`BerandaPage.vue:121`) tanpa purpose jelas.

9. **R-27 — Status UI belum diverifikasi semua halaman.** Empty/loading/error diverifikasi di Katalog/Pinjam/Cek; belum dicek cakupan admin penuh (Akun, Laporan, Pengaturan, Galat).
